# Paulo & Jana — Plantas

Demonstração temporária para apresentação ao cliente.

[Visualizar o site](https://gabrielalfa.github.io/paulo-jana-demo-20261004/) · [Conhecer a loja](https://gabrielalfa.github.io/paulo-jana-demo-20261004/loja.html)

Loja com 14 produtos de referência em seis categorias: Antúrios, Filodendros, Aráceas, Colocásias, Vasos e Acessórios. Inclui busca, filtros, ordenação e detalhes por produto. Valores e disponibilidade sob consulta.

O checkout é demonstrativo: não há criação de pedidos, envio de dados de formulário nem cobrança.

As fotografias são referências. Créditos e licenças: [fotografias](Content/Imagens/Botanica/creditos.html).

Este repositório contém a exportação estática da apresentação. Pode ser removido após a avaliação; não há exclusão automática agendada.
